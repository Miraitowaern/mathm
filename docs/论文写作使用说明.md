# MathM 0.5 · 科研与数模写作室

打开 MathM，点击左侧「论文写作」。顶部选择论文场景、正文语言、写作风格和论文类型，再选下方功能。章节和图表任务均独立保存进度和成果。

## 四个入口

| 入口 | 用法 | 交付 |
|---|---|---|
| 章节写作 | 点击章节卡片，上传真实研究材料，选择撰写或润色 | 主文档、可复用的 section.tex、简短说明，打包下载 |
| 论文图片 | 上传一份 CSV，填写实际 X/Y 列名、坐标标签与单位 | PNG 600dpi、PDF、SVG、固定 Python 脚本、源数据、插图 LaTeX 与检查记录 |
| 论文表格 | 上传一份 CSV，填写表题 | booktabs 三线表 table.tex、源数据和说明 |
| 整篇成稿 | 提供已有方法、结果、初稿及可选模板与规范 | LaTeX 项目包与简短说明 |

科研论文提供标题与关键词、摘要、引言、相关工作、方法、实验设置、结果、讨论、结论、参考文献和附录。数模场景提供摘要、问题分析、模型假设、符号、模型建立、结果、检验与灵敏度、结论、引用和附录。

## Nature 技能封装

可导入 nature-writing、nature-polishing、nature-figure 及其共享引用资源 nature-shared；这些第三方资料未随公开源码分发。科研章节撰写与润色分别读取对应技能的核心、论文类型、章节及目标风格规则。提供 Nature / Nature Communications / Nature Machine Intelligence 风格选项。

用户选择的中文或英文、章节范围、真实证据、适用规范优先于技能的默认写作语言或交付清单。内部论证规划不作为单独草稿输出。Nature 技能是写作和绘图方法指导，不代表期刊现行官方投稿要求，也不保证论文录用或成品版式合格。

## 使用边界

- 章节写作和润色需要模型接口。通过菜单「MathM → 打开模型配置」设置后重启。当前没有用真实模型完成论文质量验收；自动测试的文本模型响应采用模拟输入。
- 图表无需模型，全部本地生成。当前图片仅支持折线、柱状和散点图，不提供 AI 机制示意图或自动统计检验。
- CSV 必须为 UTF-8，首行为唯一且非空的列名。最多10000行、20列；柱状图最多40行；单表最多200行。超限或缺失/非数值数据会报错，不静默截断、丢弃数据，不自动平滑、聚合或添加误差线。
- 图片包内含静态源码检查、PDF 字号与碰撞检查的实际记录。WARN、无法审查与通过状态区分展示。数据含义、单位、统计结论和最终尺寸的视觉效果仍需作者核验。
- LaTeX 文稿和表格暂不自动编译；最终页数、字体、边距、分页和官方格式符合性仍需在可信编译环境检查。

## 模板与资源

章节可不上传模板，应用使用通用草稿外壳；它不是官方模板。上传主模板时，文件角色选「模板」，并在 document 环境内指定允许替换的区域：

```latex
% MATHM_BODY_START
这里是允许替换的正文区域
% MATHM_BODY_END
```

标记区域外的导言区、封面等保持原文。格式规范设为「规范」，初稿与研究证据设为「论文 / 支撑材料」。可附 .cls、.sty、.bst、.bib 和图片；当前直接上传同一层目录文件，暂不接收 ZIP 或多层目录。最多12个文件，单个12MB、总计24MB。

图表结果可下载后加入相应论文任务作为支撑材料；当前尚未提供跨任务自动合并和统一图表编号。

## 精简与清理

只保留最终项目包、短说明及图片预览，不输出思维过程、提纲或逐章中间草稿。原始材料、历史任务和最终成果保留；解析文字与模型过程不另存副本。

任务成功、失败或取消时清理 scratch 临时目录。异常残留在应用启动时及运行中每小时检查，超过24小时清理。关闭应用时不另设系统后台任务；下次启动补做清理。用户原件、配置与最终成果不在清理范围。

## 验证

28项自动测试通过，涵盖原有回归、按章节写作参数传递、Nature 规则匹配、语言约束、无模板章节包、真实本地绘图、表格保留数值与转义、CSV 异常处理和临时清理。桌面应用交互已在原本机安装中验证；源码单元测试使用独立的路由规则桩。文本生成质量仍需配置真实模型后用研究材料核验。

## 字体与补充提示词

「章节写作」「论文图片」「论文表格」「整篇成稿」页各有自己的「字体与补充指令」窗口。选择西文字体、中文字体及字号，再填写提示词。各功能设置彼此独立，会保存在本机，创建任务时带入；弹窗中的「本次补充提示词」可以再修改。历史任务保存当次字体及提示词，不受之后修改影响。

- 论文和表格默认跟随模板。自定义字体只作用于生成区域，使用 XeLaTeX；西文需 fontspec、中文需 ctex 或 xeCJK。提供的主模板不具备相应支持时会提示补充模板或改为跟随模板，不擅自修改模板导言区或封面。表格字体代码放在浮动表格内，避免字号被浮动环境重置。论文与表格未自动编译，字体是否安装仍需编译核验。
- 图片默认西文 Arial、8pt，中文从本机可用字体选择；可选 Times New Roman、Arial、宋体等。所选图片字体不存在时失败并提示更换，不静默替换指定字体。坐标文字采用所选字号，图例略小但不低于7pt。
- 论文提示词可写篇幅、论证重点、行文和证据要求，例如“控制在800字；先讲文献缺口；保留真实数值”，会随写作模型请求发送。无模型时不能生成章节。
- 图表仍是确定性的本地生成，当前只接受窗口列出的指令，每行一条或分号分隔，无法识别时明确报错，不会静默忽略。

图片指令示例：

```text
去掉网格
图例放在底部
显示数据点
标题：算法比较
横轴标签：时间 (s)
纵轴标签：吞吐率 (Mbps)
```

表格指令示例：

```text
表头加粗
数值列右对齐
表题：主要实验结果
```

字体名称表示具体字体，macOS 的 Songti SC 不等同于 Windows 的 SimSun；目标期刊要求具体字体时需在可信编译环境确认。字体设置不改变既有数据、统计结果和模板区域外的内容。
