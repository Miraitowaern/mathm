MODEL CONNECTION

连接你的模型

在页面填写并保存连接配置；密钥只写入本机文件，不返回浏览器。

支持提供 Chat Completions 接口的模型服务。启用后，任务中的解析文字会发送至你配置的服务商。已设置的环境变量优先级高于配置文件。

「测试连接」会先保存当前表单，再向配置的地址发一次极短请求，验证密钥、地址与模型名。桌面版也可通过应用菜单「pinkpig → 打开模型配置」直接编辑该文件。更换服务地址前请确认其可信。

当前范围

支持PDF文字提取、DOCX与文本解析。扫描PDF未做OCR；Excel 提取单元格文本（不计算公式、不做数值核验），不执行上传代码；字体、版式和数值结果需要进一步核验。
