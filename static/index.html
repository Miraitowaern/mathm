MODEL CONNECTION

连接你的模型

密钥由本地服务环境读取，不在页面中存储或展示。

支持提供 Chat Completions 接口的模型服务。启用后，任务中的解析文字会发送至你配置的服务商。

MATHM_API_KEY=你的密钥
MATHM_BASE_URL=https://api.openai.com/v1
MATHM_MODEL=服务商实际支持的模型名称

桌面版通过应用菜单「MathM → 打开模型配置」填写并保存，然后重新启动应用。命令行版使用项目目录的 .env。未配置时可直接使用本地基础检查。更换服务地址前请确认其可信。
