# pinkpig 科研平台

本地独立研究应用。两条主线：**数模求解**（通用数模竞赛与建模问题，不限定特定赛事）与**科研写作**（既写内容、也组织格式）。把本机已安装的技能接入材料上传、真实任务进度、报告与证据保存。当前版本不执行上传代码、不做自主数值求解，也不自动提交参赛作品。

## 启动

双击 `PinkPig.app`（桌面版，自带运行时与依赖），或在 Mac 终端运行 `python3 start.py --open`（网页版）。

访问 http://127.0.0.1:8765 。关闭启动终端会停止服务；重新启动后历史任务保留，处理中任务标为中断，可重试。

纯文本流程无第三方依赖。PDF / DOCX / 编译需要：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python start.py --open
```

PDF 编译与版式体检还需要本机 LaTeX（`latexmk`/`xelatex`，如 MacTeX）。

## 使用

1. 新建研究任务，选择流程：通用数模求解、对标对比、论文审查或读题建模。论文写作已升级为「论文项目」工作空间（见下）。
2. 上传文件并选择角色（赛题/问题、论文、规范、支撑材料、模板）。按页面提示设置关键材料。
3. 默认本地基础检查只提取文件文字、记录 SHA256、检查少量关键词及材料缺失；不会生成虚构 AI 审查或假进度。
4. AI 模式顺序调用实际技能，阶段结束后保存报告。进度按完成/跳过步骤计数，不是时间估算。
5. 任务列表显示排队、处理中、完成、失败、取消和中断，支持取消、失败后重试、下载报告。

### 数模求解（通用）

- **通用数模求解**：题意解析 → 建模方案 → 求解与实现 → 结果与可视化 → 复核与交付，分步复用本机 `math-modeling-skill` 的对应规则，适用于国赛/美赛/校赛/企业赛/研究生赛等各类建模问题。
- **读题建模**：题意拆解 → 建模路线 → 模型适配。
- 不限定赛事的技能都会被识别；上传“规范”可让报告以当届规则为准。

### 论文项目工作空间（科研写作）

左侧「论文项目」是**项目式**工作空间，一个项目对应一篇论文，按 9 步推进：①创建项目 ②材料/模板/格式要求/参考文献四个上传入口（含模板检查与格式清单、模板与规范冲突展示）③研究主线 ④全文提纲（区分阅读顺序与建议写作顺序）⑤三栏全文写作（待采纳草稿、采纳与版本）⑥图表（真实数据生成、统一编号）⑦分部分润色（原文/建议对照，跨章节一致性只提示不自动改）⑧全文检查（确定性 + 可选 AI，分“必须处理/建议修改/待人工核验”）⑨排版导出（LaTeX 项目包、编译成功时的 PDF、说明；数模中文默认套用国赛 `cumcmthesis`）。

- 写作只替换模板的 `% PINKPIG_BODY_START` / `% PINKPIG_BODY_END`（兼容旧 MATHM 标记）区间，禁改导言区与封面。
- 确定性检查（模板检查、格式清单、参考文献登记、图表审计、编译与版面体检）无需模型；AI 步骤（主线/提纲/写作/润色/检查）需配置模型。

## 连接模型

将 `.env.example` 复制为 `.env`，填写 `PINKPIG_API_KEY`、可信的 `PINKPIG_BASE_URL` 和 `PINKPIG_MODEL`，重新启动服务；也可在「模型连接」页填写并保存，保存后立即生效、无需重启。旧版 `MATHM_*` 名称仍可识别。密钥只写入本机文件（`0600`），不返回浏览器、不进入任务记录。AI 任务创建时必须明确确认向配置的服务发送解析文字；原文件仅保存在本地。

## 技能与执行范围

从 `~/.codex/skills` 读取技能（可设 `PINKPIG_SKILLS_DIR`）。界面按“数模 / 写作”分类展示全部已安装技能。

- 通用数模求解：`math-modeling-skill` 各阶段规则。
- 读题建模：题意拆解 → 建模路线 → 模型适配。
- 论文审查：摘要与表达 → 模型与结果 → 引用与附录。
- 其余技能显示为“已安装，暂未开放独立运行”。

模型调用各自读取同一材料包，不自动运行代码或验证 AI 给出的结论。技能 Markdown 及其直接链接的最多 4 个参考文件作为指令上下文；不加载整个参考资料库。输入文字总预算 120000 字符，单个参考文件 16000 字符，截断会披露。技能中的年份规则与评分不得直接视为官方事实，需上传适用赛事规范。

## 证据边界

支持 UTF-8/GB18030 文本、PDF 文字、DOCX 段落表格、XLSX 单元格文本。PDF 最多 200 页，不做 OCR，空白扫描页会提示。Excel 仅提取单元格文本（每个工作表前 200 行 × 20 列），不计算公式、不做数值核验；代码仅作文本，不执行。Word 不保留分页。不核验字体、页码版式或图表视觉。编译通过不等于符合官方格式；不为投稿合规、数值可复现、获奖概率或 AI 检测率作保证。

上传单文件 12MB、合计 24MB、最多 12 个文件。仅监听本机 127.0.0.1，做 Host 和 Origin 检查。未提供公网账户、多人隔离或 TLS，不应直接暴露公网。上传文档按不可信数据处理，模型提示词要求不执行其中命令。

## 保存与恢复

SQLite 记录与每个任务的独立文件目录位于 `data/`（数据库 `pinkpig.sqlite3`，旧 `mathm.sqlite3` 会在启动时自动迁移）。包含原文件、提取文本、报告及 SHA256。模型单次请求超时 180 秒，取消在当前请求返回后的检查点生效。任务失败后已生成的中间报告仍可下载。`.env`、`data/` 不应纳入版本控制。

```sh
python3 -m unittest discover -s tests -v
node --check static/app.js
```

测试使用隔离临时数据目录和模拟模型响应，不消耗真实模型额度。真实模型端到端效果需配置密钥后验证。
